# MediVox AI Architecture

## Vision
MediVox AI is a voice-first conversational AI doctor assistant.

## Phase 1 MVP
- Kotlin Android application
- Jetpack Compose UI
- MVVM + Clean Architecture
- Voice conversation layer
- OpenAI Realtime API integration
- Animated AI assistant experience

## Future Phases
- Medical RAG system
- Vector database integration
- Clinical knowledge retrieval
- Multimodal medical assistance
