# MediVox AI Assistant

MediVox AI is a conversational AI doctor assistant built with Kotlin, Jetpack Compose, and OpenAI Realtime API.

## Vision
A voice-first medical AI companion with an animated interface, real-time conversations, and future RAG-powered medical knowledge retrieval.

## Phase 1 MVP
- Kotlin Android application
- Jetpack Compose UI
- Animated AI avatar interface
- OpenAI Realtime voice conversation
- Authentication foundation
- Conversation history

## Future
- Medical RAG system
- ICD-10 knowledge integration
- Clinical guidelines retrieval
- Multimodal medical assistance
