# MediVox AI Assistant 🩺🎙️

## Overview

MediVox AI is a next-generation conversational AI doctor assistant designed around natural voice interaction. The application combines mobile AI, real-time speech conversations, animated visualization, and future medical knowledge retrieval capabilities.

The first version focuses on creating a smooth voice-first AI companion experience. Medical RAG capabilities will be introduced after the conversational foundation is stable.

---

## Vision

Create an intelligent medical AI companion that allows users to communicate naturally through voice, receive helpful health information, and interact with an emotionally engaging AI interface.
